# Задача о минимальном количестве точек

## Описание
Тестовое задание для БЮРО 1440. Задача заключается в нахождении минимального количества точек, необходимых для покрытия заданного множества отрезков на прямой.

## Условие задачи
Дано n отрезков. Каждый отрезок задается координатами своих концов. Требуется найти минимальное количество точек, таких что каждому отрезку принадлежит хотя бы одна точка.

### Примеры
```
Входные данные:
1
1 2
Результат: 1 (достаточно взять любую точку на отрезке)

Входные данные:
2
1 2
3 4
Результат: 2 (отрезки не пересекаются, нужно по точке в каждом)

Входные данные:
2
1 2
2 3
Результат: 1 (достаточно выбрать точку 2)
```

## Решение

1. Сортируем отрезки по правому концу
2. Берем правый конец первого отрезка как первую точку
3. Пропускаем все отрезки, которые содержат эту точку
4. Повторяем для оставшихся отрезков

## Входные данные
Программа читает данные из файла `data_prog_contest_problem_1.txt`:
- Первая строка: количество отрезков n
- Следующие n строк: пары чисел (начало и конец каждого отрезка)

## Выходные данные
Программа выводит одно число - минимальное количество точек, необходимых для покрытия всех отрезков.
